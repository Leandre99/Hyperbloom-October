# 🌱 Calmly — Hyperbloom October

> A calm, adaptable learning space for neurodivergent students (ADHD, dyslexia).
> Built for the **HyperBloom October 2026 — UI/UX & Web Design Hackathon**.

🔗 **Live demo:** https://leandre99.github.io/Hyperbloom-October/

## The problem
Learning platforms like Moodle or Google Classroom are visually overloaded and poorly adapted to attention disorders or dyslexia.

## The solution (in progress)
- 🎛️ Sensory profile onboarding — font, contrast, motion, density
- 🎯 Focus mode — one thing at a time
- 📖 Accessible reader — OpenDyslexic, reading ruler, text-to-speech
- 🪜 Micro-steps with gentle visual rewards
- ⏱️ Pomodoro timer + mood & energy check-in
- 🌍 Bilingual English / Français

## Tech
React · Vite · TypeScript · CSS custom properties · GitHub Pages
